# Public-name research

Research started on 2026-09-25. **AgentRail is a working name only.**

The initial search found direct collisions in the same technical area:

- [yai-dev/agentrail](https://github.com/yai-dev/agentrail): an agent harness framework.
- [AgentRail](https://agentrail.app/): a coding-agent product.
- [Agent-Rail GitHub organization](https://github.com/Agent-Rail): agent allowance tooling.

The charter also flags AgentForge as already used. Neither name is approved for
public launch. Keep local identifiers stable during foundational work; decide on
a distinct name before publication. Next research should shortlist alternatives,
check GitHub, package registries and domains, and review relevant trademark
registers. Search findings are collision evidence, not legal clearance.
