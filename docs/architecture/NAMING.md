# Public-name research

Research started on 2026-09-25 when the project was called AgentRail. The
repository has since been renamed internally to **Runveil**. This record keeps
the original collision research, which applies to the former name only.

The initial search found direct collisions in the same technical area:

- [yai-dev/agentrail](https://github.com/yai-dev/agentrail): an agent harness framework.
- [AgentRail](https://agentrail.app/): a coding-agent product.
- [Agent-Rail GitHub organization](https://github.com/Agent-Rail): agent allowance tooling.

The charter also flags AgentForge as already used. Runveil is the current
working name, not an approved public launch name. Before publication, shortlist
alternatives and check GitHub, package registries, domains, and relevant
trademark registers. Search findings are collision evidence, not legal
clearance.
