# Project name and historical research

Runveil is the name used for this development/portfolio repository. Making its
source public is not a product launch and does not require a domain, a rebrand,
or a naming-clearance gate. This scope was clarified by the owner on 2026-10-01.

Research started on 2026-09-25 when the project was called AgentRail. The
repository has since been renamed internally to **Runveil**. This record keeps
the original collision research, which applies to the former name only.

The initial search found direct collisions in the same technical area:

- [yai-dev/agentrail](https://github.com/yai-dev/agentrail): an agent harness framework.
- [AgentRail](https://agentrail.app/): a coding-agent product.
- [Agent-Rail GitHub organization](https://github.com/Agent-Rail): agent allowance tooling.

The original charter also flags AgentForge as already used. Its public-launch
naming requirement describes a possible future product launch, not a prerequisite
for sharing this repository. The historical search findings concern the former
names; they do not establish clearance or a collision for Runveil.
